欢迎使用 **HugoPad** 🎉

- 📝 写作：自动补全 Hugo front matter（标题/日期/标签）
- 🎨 主题：一键安装开源主题并预览
- 🔨 构建：内置 Hugo 引擎，本地即时预览
- ☁ 部署：提交并推送到 Git 仓库，配合腾讯 EdgeOne Pages 自动发布

```bash
hugo server  # 电脑上也可以这样本地预览
```

> 保存文章时，如果标签为空，HugoPad 会根据内容自动推荐标签。
